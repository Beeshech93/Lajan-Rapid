# lajan rapid

La aplicación tendrá

👤 Para clientes

Registro e inicio de sesión.

Verificación de identidad (KYC).

Enviar dinero de México a Haití.

Elegir método de pago (Mercado Pago, transferencia, OXXO, etc.).

Consultar el tipo de cambio.

Ver el estado de las transferencias en tiempo real.

Historial de envíos.

Notificaciones push.

👨‍💼 Para agentes

Inicio de sesión.

Recibir solicitudes.

Confirmar pagos.

Consultar saldo y comisiones.

Historial de operaciones.

🛠️ Para administradores

Panel web para gestionar usuarios, agentes y transacciones.

Aprobar o rechazar verificaciones KYC.

Configurar tipos de cambio y comisiones.

Generar reportes y estadísticas.

Controlar las billeteras y los pagos.

Tecnología

App móvil: React Native (Android e iPhone).

Backend: Node.js + Express.

Base de datos: PostgreSQL.

Panel administrativo: Next.js.

API: REST con autenticación JWT.

Diseño

La interfaz será moderna y sencilla, similar a aplicaciones como Remitly o Wise, con:

Pantalla de bienvenida.

Inicio de sesión.

Inicio (Dashboard).

Enviar dinero.

Historial.

Perfil.

Soporte.
